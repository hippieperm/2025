# 쇼핑몰 콘솔 애플리케이션

## 프로젝트 소개

이 프로젝트는 Dart 언어로 개발된 간단한 콘솔 기반 쇼핑몰 애플리케이션입니다. 사용자는 상품 목록을 확인하고, 장바구니에 상품을 담고, 장바구니에 담긴 상품의 총 가격을 확인할 수 있습니다.

## 주요 기능

1. **상품 목록 보기**: 쇼핑몰에서 판매 중인 모든 상품과 가격을 확인할 수 있습니다.
2. **장바구니에 담기**: 원하는 상품을 선택하고 수량을 입력하여 장바구니에 담을 수 있습니다.
3. **장바구니 총 가격 보기**: 장바구니에 담긴 모든 상품의 개별 가격과 총 가격을 확인할 수 있습니다.
4. **장바구니 초기화**: 장바구니에 담긴 모든 상품을 한 번에 비울 수 있습니다.
5. **프로그램 종료**: 쇼핑몰 애플리케이션을 종료합니다.

## 프로젝트 구조

```
lib/shopping_mall/
├── main.dart           # 메인 애플리케이션 진입점
├── data/
│   └── shopping_mall_data.dart  # 상품 및 장바구니 데이터 관리
└── service/
    └── shopping_mall_service.dart  # 비즈니스 로직 처리
```

## 사용 방법

1. 프로그램을 실행하면 메인 메뉴가 표시됩니다.
2. 원하는 기능의 번호를 입력하여 해당 기능을 사용할 수 있습니다:
   - `1`: 상품 목록 보기
   - `2`: 장바구니에 상품 담기
   - `3`: 장바구니에 담긴 상품의 총 가격 보기
   - `4`: 프로그램 종료
   - `6`: 장바구니 초기화
